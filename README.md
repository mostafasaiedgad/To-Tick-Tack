# To-Tick-Tack
It is to-do-list app that helps you to prioritize your tasks in day or planning for future. It will have several features begining to add tasks, store them in local storage, log in system, delete tasks, finish them. I will made this web using HTML, CSS, and Javascript.
## HTML Structure
- I will made sections for main 
- section for tasks
- the responsible about the components of tasks
## CSS 
- decorating the html tags and elements
- responsible for the decorating the tasks and the component elements that are made by HTML
## Javascript
- The responsible about adding, deleting, finishing process in the tasks not its shape and components
